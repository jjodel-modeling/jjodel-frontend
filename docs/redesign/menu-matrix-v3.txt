JJODEL - MENU STATE MATRIX
===========================

Last Updated: January 2026 (v3)


STATI DEL SISTEMA
-----------------

| Stato | Descrizione                                      |
|-------|--------------------------------------------------|
| S0    | Logged out (pagina Auth - nessun menu)           |
| S1    | Dashboard vuota (0 progetti)                     |
| S2    | Dashboard con progetti (≥1 progetto)             |
| S3    | Progetto aperto, vuoto (0 metamodels)            |
| S4    | Progetto aperto, con metamodel(s), 0 models      |
| S5    | Progetto aperto, con metamodel(s) e model(s)     |
| S6    | Progetto aperto, con metamodel Editor aperto     |
| S7    | Progetto aperto, con model aperto                |


LEGENDA
-------
E = Enabled (abilitato)
D = Disabled (disabilitato)
DYN = Dinamico (contenuto varia in base al metamodello)
— = Separatore nel menu

BOTTOM TOOLBAR (sopra il footer)
--------------------------------

Visibile solo in S6 e S7 (editor aperto).

| Sezione          | Contenuto                              | Note           |
|------------------|----------------------------------------|----------------|
| Tools Commands   | [Cmd1] [Cmd2] [Cmd3] ...              | DYN dal metamodello |
| Canvas Toggles   | Grid [✓]  Snap [✓]                    | Toggle on/off  |
| Zoom Controls    | [−] 100% [+]                          | Zoom level     |

Layout:
```
┌────────────────────────────────────────────────────────────────────────┐
│ [Cmd1] [Cmd2] [Cmd3]  │  Grid [✓]  Snap [✓]  │  [−] 100% [+]         │
│ ← Metamodel tools      │  ← Canvas toggles     │  ← Zoom controls     │
└────────────────────────────────────────────────────────────────────────┘
```

La sezione "Metamodel tools" è dinamica:
- Vuota se il metamodello non definisce comandi custom
- Popolata con i comandi registrati dal designer del metamodello
- Stessi comandi presenti nel menu Tools ▾


NOTE
----
- S0 (Logged out) = pagina Auth, nessun menu visibile
- Sign out è SOLO nel menu Avatar (rimosso da menu Jjodel)
- Il menu Tools appare da S4+ ma può essere vuoto se nessun comando definito
- I comandi metamodel-specific appaiono sia in Tools menu che in Bottom Toolbar
- Il menu Help è sempre completamente abilitato
- I separatori (—) sono sempre presenti
- "Recent Projects" mostra lista dinamica dei progetti recenti
- Theme è gestito nel menu Avatar (Light/Dark)
