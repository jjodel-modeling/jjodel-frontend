## Structural notes discovered

- `~/jjodel-release` is a worktree of `~/jjodel/.git`: git from the bridge VM fails with «not a git repository»; every git command runs through osascript `do shell script`, the bridge only reads files and writes them with `device_commit_files`.
- `lane-run` (`frontend/scripts/lane-run.mjs`, run with `~/.local/bin/node`, v26) was committed locally before the public branch had it; a shallow public clone is not a reliable oracle for what exists on Alfonso's trunk.
- The Bash tool of a `-p` session is zsh: an unquoted glob that matches nothing fails before git runs, so a `git ls-files` control on removed paths must quote its pathspec.
- `git grep -w` discriminates the study's four-letter name from `themselves`, `NodeProblemSeverity` and the Ace editor identifiers; a substring grep does not.
- GitHub's HTML and API are not reachable from the chat's web fetch; a shallow `git clone --filter=blob:none` of the public branch in the cloud workspace is the way to audit what is online.
