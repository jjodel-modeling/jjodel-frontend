## Info strutturali scoperte

- rc-dock nasconde un tab inattivo con `visibility: hidden` e offset fuori schermo (`DockTabPane.js:59-69`); un portal
  su `<body>` ne esce. `.pinnable-dock-root` ha `transform-style: preserve-3d` (`DockManagerStyles.scss:133`) e forma
  un contesto di stacking; `#root` è `position: fixed`.
- `updateDefaultView` (`view.tsx:1989`) ricostruisce la view migrata conservando solo `ir`: qualunque metadato della
  view deve vivere dentro `ir`.
- Solo la migrazione produce view di default che rendono nativo; le view dal «+», per classe o da Enable IR non hanno
  `migratedFrom`.
- In JjEL `and`/`or` sono eager; `implies`, `if`, `?.`, `??` fanno short-circuit. La via B dell'evaluatore non ha
  `now()` né builtin di data. `proxy.ts` non ha trap di freeze: congelare un proxy L congela l'oggetto dietro.
- Il plugin VS Code di Claude Code lega la sessione alla cartella della finestra.
- Il symlink P14 `frontend/node_modules → ~/jjodel/frontend/node_modules` fa servire i font via `/@fs/` fuori dalla
  root: 403 in Vite.
