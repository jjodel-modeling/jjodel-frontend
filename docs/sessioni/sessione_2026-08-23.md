## Bug risolti

**`.git/index.lock` non cancellabile dal bridge.** Diagnosi: il bridge non può fare `unlink`, quindi
ogni `git status` normale lascia un lock che poi blocca i commit dal Mac. Rimedio: `mv` invece di
`rm` (il rename è permesso), e `git --no-optional-locks` per le letture. Stesso trattamento per
`HEAD.lock`, che un commit fallito lascia dietro. **Conseguenza grossa: dal bridge si committa**, cosa
che il checkpoint del 21/8 dava per impossibile.
