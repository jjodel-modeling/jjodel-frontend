## COME

### The row grammar, measured on `docs/decisions.md` at `d78f1981b`

A row is a line starting with `- **<ID>** (` where `<ID>` matches `R[A-Z]*-?[A-Z]*-?\d+` (`RC-30`, `R-SIM-77`, `R-EDGE-1`, `R-VAL-3`, `R-MCID-1`…). The parenthesis holds comma-separated fields: a date `YYYY-MM-DD` first, then any of `provisional`, `unattended`, `evidence: measured|read|inferred`, `verified: agent|none`, `reversible: branch|trunk|persisted`. Then `:` or `.` and the text; the title is the first `**…**` after the header when present, else the first sentence, clamped to 120 characters. Shapes present today: `(2026-09-26)` 19 rows; `(2026-09-26, provisional, unattended)` 6; `(2026-09-27, provisional, unattended)` 1; the full six-field form 11 rows. The section a row belongs to is the nearest preceding `## ` or `### ` heading. A row keeps its line number.

### Confidence

`ratified`: no `provisional` marker (Alfonso's own rows). Otherwise, from the fields: `high` = evidence `measured` and verified `agent`; `medium` = (`measured` and `none`) or (`read` and `agent`); `low` = evidence `inferred`, or (`read` and `none`); `unmarked` = provisional without the three fields (the 2026-09-26 rows, before RC-25's grammar). `reversible` does not change the label; it is printed beside it, because a `low` on a branch and a `low` persisted call for different attention.

### The rendered file

`docs/digest/<date>.md`, in English, no em dashes, this order: an H1 `Decisions digest <date>`; one line `Generated by npm run docs:digest from docs/decisions.md at <short sha of HEAD>; rows dated <date>: N (ratified R, provisional P: high H, medium M, low L, unmarked U); reversible: branch B, trunk T, persisted S.` (the RC-28 counts); then one H2 per section in file order, each row one line: `- **ID** · confidence · evidence/verified/reversible · title (decisions.md:LINE)`, provisional rows before ratified within a section, `low` first; then the marker line `<!-- digest:manual -->` and everything after it, preserved verbatim from the existing file when one exists, else a stub `## For Alfonso\n\n(hand-written by the chat: RC-26 items, deviations, tickets)\n`. Options: `--date YYYY-MM-DD` (default today, local), `--write` (else print to stdout), `--all` (every date that has rows, one file each, for a backfill; not used in this lane beyond a dry run). Exit 0 always when the register parses; exit 2 on a header it cannot parse, printing the line.
