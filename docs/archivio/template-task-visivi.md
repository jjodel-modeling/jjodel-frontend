## Template Recovery — Task Visivi / Posizionamento (qualsiasi area)

Prima di generare il prompt di implementazione per un task visivo
(posizionamento, colori, layout, spacing, animazioni):

1. **Cosa si vede adesso** — numeri concreti (coordinate, px, indici)
2. **Cosa deve diventare** — stesso livello di precisione
3. **Criterio di accettazione** — una frase meccanica verificabile

Se il Direttore non fornisce questi 3 punti, NON generare il prompt.
Chiedi esplicitamente. Il costo di una domanda in più è zero;
il costo di 5 fix consecutivi sullo stesso file è alto.
