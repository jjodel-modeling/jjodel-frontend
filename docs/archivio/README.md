# docs/archivio

Materiale di lavoro storico archiviato dal Project Knowledge: backlog, censimenti, mappe,
proposte, review, verifiche, kickoff. Non è normativo — le spec vigenti stanno in `docs/spec/`,
i vincoli attivi in `docs/decisions.md`. In `artefatti/` gli allegati non testuali (snippet,
mockup, cruscotti).
