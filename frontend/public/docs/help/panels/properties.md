# Properties Panel

The Properties panel displays and lets you edit the attributes of the currently selected element on the canvas.

## Selecting Elements

Click any class, enum, or package on the canvas to see its properties here.

## Editing

- **Name** — rename the element
- **Abstract** — mark a class as abstract (metamodel mode)
- **Attributes** — add, edit, or remove attributes
- **Operations** — add, edit, or remove operations
